Topic: How to write to serdev device from Rust

Ayush Singh (Aug 19 2026 at 11:36):

The current serdev API supports writing when the device context is Bound. This is fine for writing from probe or receive callbacks. However, when converting to recounted ARef<Device>, only conversion to Normal device context is possible. So how is someone supposed to write from say a workqueue or any other callback?
The only way I have found so far is to step down to normal device, covert it to bound using as_bound and then get back the serdev device using Device::from_device unsafe function:

        let bound: &serdev::Device<Bound> =
            unsafe { serdev::Device::from_device(self.sdev.as_ref().as_bound()) };

Is this the expected way to do this, or maybe I am missing something?
