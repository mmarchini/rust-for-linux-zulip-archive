#[stable(feature = "boxed_closure_impls", since = "1.35.0")]
impl<Args: Tuple, F: FnOnce<Args> + ?Sized, A: Allocator> FnOnce<Args> for Box<F, A> {
    type Output = <F as FnOnce<Args>>::Output;

    extern "rust-call" fn call_once(self, args: Args) -> Self::Output {
        <F as FnOnce<Args>>::call_once(*self, args)
    }
}

bjorn3 (Oct 17 2026 at 17:23):

The FnOnce() for Box<dyn FnOnce()> impl uses #![feature(unsized_fn_params)] (to allow passing dyn FnOnce() directly as argument to call_once) together with the fact that rustc special cases Box to allow moving out of it (which because of unsized_fn_params will not actually copy the raw bytes).
