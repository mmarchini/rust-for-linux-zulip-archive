Topic: Explicit self-ref borrow syntax

Gary Guo (Sep 19 2026 at 18:19):

In my current impl, I use a syntax borrowed from ouroboros.

#[covariant]
#[borrows(owner, mut another)]
f: Foo<'owner, 'another>,
#[not_covariant]
b: Bar<'owner>,

however, there is no way to say "covariant over this lifetime, but invariant over another". As outlined in my talk, invariance propagates across borrows, so I think a more precisely way of doing this is per-lifetime specification of variance.

Also, I am think the fact that mutable borrowing is specified on the borrower, but has effect on the borrowed field is strange, especially that if one field borrows another mutably, all fields can use that mutable borrow. So I have the following alternative design:

#[borrowed] // Explicitly mark self-ref, useful as the field order outlive bounds can be used to coerce to the field lifetime of earlier field
owner: String, // shared self-ref
#[borrowed(mut)]
mutable_owner: String, // mutable self-ref
#[captures('owner)] // Explicit specification, default to covariance
f: Foo<'owner>,
#[captures(covariant 'owner, invariant 'another)] // Explicit variance specification
b: Bar<'owner, 'another>,
#[captures(invariant '_)] // Auto field capture, but make all captures invariant.

Gary Guo (Sep 22 2026 at 10:40):

I did some experiment I think I do like the #[borrowed(mut)] change so will go with that.

For the #[borrows] / #[captures] -- I think the per-lifetime variance is a useful thing to have, but I am uncertain what name do I want to use, and would like some feedbacks. The #[borrows] feel more natural with regard to fields; however it looks weird with respect to existential lifetimes.
