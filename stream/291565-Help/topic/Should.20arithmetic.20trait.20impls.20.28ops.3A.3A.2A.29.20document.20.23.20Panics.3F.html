Topic: Should arithmetic trait impls (ops::*) document # Panics?

George Androutsopoulos (Aug 31 2026 at 23:57):

Hello! In rust/kernel/time.rs, Delta wraps an i64 and implements standard arithmetic traits (ops::Add, ops::Sub, ops::Mul, ops::Div, etc.). These implementations can panic (when overflow checks are enabled), but don't have a # Panics section in their docs.

Is omitting # Panics sections for standard ops:: trait implementations an intentional convention across the rust/kernel because arithmetic panics are expected in Rust when overflow checks are enabled? Or should panic conditions be explicitly documented on arithmetic trait overloads for Delta?

Miguel Ojeda (Sep 01 2026 at 00:08):

Operators like + may panic if used incorrectly, so other operators defined like that are to be expected to panic. Having said that, documenting it explicitly sounds good if the timekeeping maintainers are OK with it (I guess it depends on how much repetition it adds).
