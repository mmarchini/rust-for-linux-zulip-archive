Pierre Barre (Jul 31 2026 at 21:02):

Hi!

I recently ported the ZeroFS (https://github.com/Barre/ZeroFS) userspace filesystem client to an out-of-tree Linux kernel module written in
Rust (https://github.com/Barre/ZeroFS/tree/main/kernel).

It uses netfslib (https://docs.kernel.org/filesystems/netfs_library.html) and currently supports:

  • Mounting, lookup, attributes, directory iteration, and statfs
  • File and directory creation, rename, unlink, hard and symbolic links, device nodes, and FIFOs
  • Persistent opens and atomic_open
  • Buffered I/O, dirty-folio writeback, writable mmap, and direct I/O
  • fallocate, SEEK_DATA, SEEK_HOLE, POSIX record locks, flock, and fsync

The build also has a self-contained path for a limited set of supported kernels built with CONFIG_RUST=n.

I thought this might be of particular interest to people here, and I’d be interested in feedback on the overall approach.

Thanks!
